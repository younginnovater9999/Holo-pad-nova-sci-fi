# Holo-pad-nova-sci-fi
HoloPad is an AI-powered interactive display system powered by Nova. It aims to combine machine learning, voice interaction, webcam-based gesture recognition, touchscreen controls and motorised movement. Hardware integration and mechanical design are currently in progress. Nova's source code remains private while development continues.
HoloPad — Powered by Nova

HoloPad is an AI-powered interactive display system designed to integrate Nova with a physical touchscreen environment.

Key Features

- AI assistant integration
- Voice interaction
- Webcam-based gesture recognition
- Touchscreen interface
- Motorised display movement

Hardware

- Raspberry Pi 5 (planned)
- 55-inch touchscreen (planned)
- Webcam
- Motorised assembly

Development Status

Software development and hardware planning are ongoing. Nova's source code remains private.

Goal

Build an interactive AI workstation combining software intelligence and physical hardware.HoloPad System Architecture

1. Central Intelligence

Nova is the AI assistant responsible for processing user requests and coordinating system functions.

2. Visual Input

A webcam is planned to capture visual input for gesture recognition.

3. Display System

A 55-inch touchscreen is proposed for visual output and user interaction.

4. Computing Unit

A Raspberry Pi 5 is proposed as the primary hardware controller.

5. Motion System

Motorised components are planned to support physical display movement.

6. Integration

The objective is to connect Nova, visual input, touchscreen interaction and motor control into one unified system.
